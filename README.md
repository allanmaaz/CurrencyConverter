# 💱 Currency Converter  

A simple and responsive **Currency Converter Web App** built with **HTML, CSS, and JavaScript**.  
It allows users to convert between different currencies in real-time using a clean and modern interface.  

🚀 **Live Demo:** [Currency Converter](https://allanmaaz.github.io/CurrencyConverter/)  

---

## ✨ Features  
- 🌍 Convert between multiple world currencies.  
- 🔄 Real-time exchange calculation.  
- 🎨 Simple, modern, and responsive UI.  
- 📱 Works on desktop and mobile devices.  

---

## 🛠️ Tech Stack  
- **HTML5** → Structure of the app  
- **CSS3** → Styling and responsiveness  
- **JavaScript (ES6)** → Logic and interactivity
